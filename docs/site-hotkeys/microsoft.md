All origins are unconfirmed (not loaded in a browser). Verified means read on the vendor page this session via a summarizing fetch tool.

## Windows input switching (OS level) (windows-input-switching)

Origins: *

| Windows | Mac | Action | Family | Verified |
|---|---|---|---|---|
| alt+shift | - | Left Alt+Shift switches input language (default when several languages are installed; can be changed or set to Not Assigned under Advanced keyboard settings, Input language hot keys) | alt+shift | false |
| ctrl+shift | - | Ctrl+Shift switches keyboard layout when multiple layouts are available | ctrl+shift | true |
| meta+space | - | Windows+Space switches forward through input languages and layouts (Win+Shift+Space backward) | alt+shift | true |

Notes and gaps: Whether the page still receives the keydown is NOT confirmed from a Microsoft page. Expected behavior (unverified): the switch triggers when the bare modifier pair is released with no other key, browsers still see keydown for Shift and Alt, and Shift+Alt+<key> chords are not stolen. Needs a live test.

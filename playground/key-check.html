Key check

A manual check of how real browsers report keys on other keyboard layouts and with an IME, for the cases simulated events cannot prove. Serve the repo root over HTTP (module scripts do not load from file://), for example python -m http.server 8080, and open http://localhost:8080/playground/key-check.html. The page uses the source files, so no build is needed.

For each row: switch the OS keyboard layout or IME, click the page outside the text field (unless the row says otherwise), press the keys, and compare the Fired column of the event log with the expectation. Then set the result. Do it in Chrome and Firefox, and use Copy results to paste a note into docs/notes/.

Bindings on this page

Only chords that no browser takes for itself (from the reservation table), so a miss means the router missed it, not the browser. mod is Cmd on macOS, Ctrl elsewhere.

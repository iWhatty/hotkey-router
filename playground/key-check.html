Key check

Checks how real browsers report keys on other keyboard layouts and with an IME, which simulated events cannot prove. No special keyboard is needed: Windows (or macOS) decides what each physical key types, so switching the OS layout turns any keyboard into a Russian or Greek one.

Automatic (Windows): run scripts/key-check.ahk with AutoHotkey 1.1. It starts the local server, opens this page in Chrome, Firefox and Edge, switches layouts for the session only, presses the keys, and writes one note per browser to docs/notes/. Don't touch the keyboard while it runs; press Pause to stop it.

By hand: npm run key-check, open http://127.0.0.1:8080/playground/key-check.html, switch the OS layout (Win+Space on Windows), click Run on a row, and press its keys. The row grades itself. Copy results gives a Markdown note.

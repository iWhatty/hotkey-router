Reserved key check

Is a key the browser-hotkeys table marks hard really out of a page's reach? Every combo below is bound with preventDefault: true. scripts/key-check-reserved.ahk presses each one for real (US layout) and watches the browser; this page reports what it saw to the local server (npm run key-check): each keydown, each handler that fired, and the signs of the browser acting anyway (focus leaving the page, the tab hidden, the page unloading, a resize from a sidebar, copy/cut/paste, a selection). node scripts/key-check-reserved-report.mjs writes the note.

By hand: run the server, open this page, press a key, watch the log. ?bound=0 binds nothing, to see what the browser does on its own.
